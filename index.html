PixelJunk Monsters Web Level Editor

Welcome! This is a suite of browser-based proofs of concept (PoCs) working towards a full web-based level editor for PixelJunk Monsters Ultimate on PC.

Available Tools

Archive Repacker

Instantly extract and repack monsters.pkdwin game archives. Allows injecting modified assets.

Map Viewer

Interactive viewer for rendering game levels, routes, and object placement directly from the archives.
